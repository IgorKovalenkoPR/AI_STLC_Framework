## Що потрапляє в `Actual, %`

Комірка отримує **або число (частка, формат `0.0%`), або рівно один із п'яти текстових рядків**:

| Значення | Коли | Формат | Колір |
|---|---|---|---|
| число, напр. `-0.32` | є години або оцінка діапазоном | `0.0%` | зелений / червоний |
| `0% — ще не використовуємо` | статус `NOT_YET` | `@` | янтарний |
| `N/A — специфіка продукту` | статус `NA_PRODUCT` | `@` | сірий |
| `N/A — NDA / приватність даних` | статус `NA_NDA` | `@` | сірий |
| `N/A — немає автоматизації / CI-CD` | статус `NA_TOOLING` | `@` | сірий |
| `Немає даних` | фаза позначена як «використовуємо», але немає ні годин, ні оцінки | `@` | сірий курсив |

**Чому `NOT_YET` — це текст, а не число 0.** Для менеджера «0%, бо не пробували» і
«0%, бо AI не дав вимірюваного ефекту» — різні висновки. Друге приходить як справжній
числовий `0.0` з варіанта `Без змін (0%)` і фарбується червоним (ціль не досягнута).
Перше — янтарним: це не провал, це нереалізована можливість.

### Наслідок для формул у таблиці

Текст лежить у тій самій колонці, що й числа. Google Sheets ігнорує текст у `AVERAGE`,
`SUM`, `MIN`, `MAX` — вони працюють коректно. **Не використовуйте `AVERAGEA`**
(вона рахує текст як 0 і занижує середнє).

Безпечні варіанти для зведених показників:

```
=AVERAGE(F4:F19)                      середнє по заповнених числових
=COUNT(F4:F19)                        скільки проєктів дали цифру
=COUNTIF(F4:F19;"N/A*")               скільки проєктів позначили фазу як незастосовну
=COUNTIF(F4:F19;"0% — ще не використовуємо")  скільки могли б, але ще не почали
```

## Умовне форматування

Порядок правил (перше збіжне виграє), накладається на `F4:F…` і далі по кожній Actual-колонці:

1. **Янтарний** `#fff2cc` — `=EXACT($F4,"0% — ще не використовуємо")`
2. **Сірий курсив** `#efefef` — `=AND(ISTEXT($F4),$F4<>"")` — решта текстових міток
3. **Зелений** `#d9ead3` — `=AND(ISNUMBER($F4),ISNUMBER($E4),$F4<=$E4)`
4. **Червоний** `#f4cccc` — `=AND(ISNUMBER($F4),ISNUMBER($E4),$F4>$E4)`

Для колонки **N** (Виконання тестів, додатний таргет) порівняння інвертоване:
зелений `$N4>=$M4`, червоний `$N4<$M4`.

`applyFormatting()` спершу знімає **всі** правила, що зачіпають колонки Actual — і власні
з попереднього запуску, і широкі правила, успадковані з `.xlsx` (інакше вони вигравали б
за порядком і перекривали кольори текстових міток). Правила на інших колонках не чіпаються.
